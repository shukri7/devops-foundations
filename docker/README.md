# Docker Projects

## Overview
Hands-on Docker projects focused on containerizing applications, managing multi-container environments, networking, scaling, and persistent storage.

## Technologies Used
Docker, Docker Compose, Python, Flask, MySQL, Redis, and Nginx.

## What I Did
- Containerized a Flask application using Dockerfiles and explored multi-stage builds.
- Built a Flask and MySQL environment using Docker Compose.
- Deployed a multi-container visitor counter using Flask, Redis, and Nginx.
- Configured Nginx as a reverse proxy and scaled Flask to three replicas.
- Implemented Docker volumes for Redis data persistence.

## Results
- Successfully ran and connected multiple containerized services.
- Exposed the visitor counter through Nginx on port `8080`.
- Verified communication between Flask and Redis across three Flask replicas.
- Practiced container management, networking, scaling, and persistent storage.
